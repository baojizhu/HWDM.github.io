# Web Project Documentation

## Overview
This web project is designed to showcase the company "ZHELISHI" with a visually appealing webpage. The webpage features a transparent logo background, the company name prominently displayed, and links to various sections including company introduction, product services, cultural product display, and contact information.

## Project Structure
```
web-project
├── src
│   ├── assets
│   │   ├── css
│   │   │   └── styles.css
│   │   ├── images
│   │   │   └── logo.png
│   │   └── js
│   │       └── script.js
│   ├── index.html
├── package.json
└── README.md
```

## Features
- **Transparent Logo Background**: The logo is displayed with 10% transparency, creating a modern aesthetic.
- **Company Name**: The name "ZHELISHI" is prominently positioned over the logo.
- **Navigation Links**: Easy access to different sections of the website:
  - Company Introduction
  - Product Services
  - Cultural Product Display
  - Contact Information

## Setup Instructions
1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Install the necessary dependencies using npm:
   ```
   npm install
   ```
4. Open `src/index.html` in a web browser to view the webpage.
